### Central Acadêmica Inteligente Online

*Uma interface inteligente entre estudantes e informações acadêmicas.*

</div>

O **C.A.I.O.** é um projeto de assistente acadêmico virtual desenvolvido para facilitar o acesso dos alunos às informações da turma e reduzir perguntas repetitivas direcionadas ao representante.

**Objetivos do projeto**

- Centralizar informações acadêmicas organizadas por categoria.
- Facilitar consultas sobre atividades, prazos, avisos e orientações disponibilizadas.
- Apoiar a comunicação entre estudantes e representação de turma.
- Explorar agentes de IA generativa em um cenário acadêmico real.

**Tecnologia principal:** Microsoft AI Foundry e recursos de IA generativa.

> O C.A.I.O. é um projeto em desenvolvimento. As funcionalidades apresentadas correspondem aos objetivos do projeto e não implicam que todos os recursos já estejam implementados.

**Repositório:** adicione aqui o link específico do C.A.I.O. quando o projeto estiver publicado.
